    What is Pretend Internet?

    What this is: A local-first portfolio home connecting independent offline mini-apps and tools. Each place works on its own without requiring an account, wallet, or server.

    How to begin: Browse or search the Places grid, open any app (such as Pocket Reader, Pocket Notes, or Nsite Directory), save your work locally, and return later via your pinned places or recent strip.

    What is functional vs. untested: Browser runtime, unit tests, and local persistence are verified for the web apps here. Status labels distinguish testing (browser-tested), wip (template), and live (Folder Launcher's owner-attested Android APK; this page opens its HTML fallback). No full portfolio Android APK has been verified.

    Discovery boundary (PI-04): The Nsite Directory inspects Nostr event metadata only and never automatically fetches remote HTML, assets, ZIPs, or screenshots.

    Where your data goes: Skin choice, pins, recent visits, and personal shelf bookmarks stay strictly in this browser's localStorage. Nothing is sent over a network.
