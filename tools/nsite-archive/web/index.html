Search the text inside archived sites, including sites without a published title. Open a site to browse its pages, signed publications, versions and relationships.

Import a directory.json export to begin. Everything you import stays in this browser. Collecting sites and capturing safe previews happens in the local archive worker; this viewer makes no relay or signer connections.

Filters only hide results. “Show filtered” reveals them; no archived files are removed. Exact content is verified by hashes. Declared relationships are publishers’ claims; probable clones are unverified similarities.

For a self-contained offline collection, keep this folder and its previews together. The worker’s SQLite database and objects folder hold the restorable original bytes.
