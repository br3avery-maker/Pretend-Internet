Help

Find and save sites

Open Collect, choose relays or selected nsite URLs, and start. Signed events and their declared files are verified before they are treated as complete. You can also import signed JSON or NDJSON events. Pause, close, and resume later; completed files and pending jobs remain saved.

Browse, search and recover

The Library searches publisher metadata and indexed text from saved files. Open a site to read archived page text, inspect its versions, compare changed paths and chunk reuse, or restore verified files as a ZIP. Publishers groups useful sites by author and site count.

Confirmed spam exclusion

The manually confirmed campaign signatures are excluded from normal library results, searches, publisher groups and related-site suggestions. Existing raw records remain available in a full archive backup. Unrelated prolific publishers and one-page sites are not excluded by those characteristics.

Privacy and networking

Data stays in this browser's local IndexedDB database. No account, signer, or publication is required. Configured relays and file servers see requests; an explicitly configured proxy also sees requested URLs. CORS, unreachable servers and relay history limits may prevent complete collection. No downloaded site scripts run during text indexing.

Storage and recovery

Export full backups regularly. Browser storage is origin-specific and may be evicted. Import verifies signed events and object hashes before committing records. If an operation stalls, Cancel operation stops its worker; completed writes remain. Pause collection before importing or exporting.

Directory and downloads

The Directory contains complete publications, with exact-content deployments stacked together. Incomplete sites stay in Downloads. Each incomplete site and file has a download/retry action; saved pages can be indexed immediately. Indexing reads actual page text, headings and metadata, derives descriptions and topics, and applies the confirmed campaign exclusions.

Previews and saved sites

Previews are PNG captures of safely rendered archived HTML and available local styles/images. They are not Open Graph pictures. Scripts, remote requests and active controls are disabled; a JavaScript-only application may need its original host or restored ZIP to run. Missing resources remain visible. Read derived text or open the saved static page from the site screen.

Collection continuity

Collection resumes durable work automatically on every app page. A document change restarts its worker from committed checkpoints; it does not require another manual Start. Pausing is explicit. Network failures use timed automatic retry; selected total-transfer or file limits pause work. Mobile OS suspension may stop execution; opening the app resumes saved work without discarding partial files.

Storage on this phone

The full verified archive is stored locally in IndexedDB, using content-defined chunks and Merkle records. Identical bytes are shared without merging signed publisher histories. Blossom servers are retrieval sources; no remote storage account is required. Backup shows local usage, requests browser persistence and exports a portable archive containing bytes and provenance. Browser/WebView storage is origin-specific and can be cleared by the OS or app settings; export backups before changing hosting origins or reinstalling.
