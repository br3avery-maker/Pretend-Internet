Nsite Directory — Help

What this is: A strictly metadata-only Nsite directory and NIP-01 event inspector built to honor the PI-04 discovery boundary.

How to start: Import a local Nostr event JSON/NDJSON file, click Paste JSON, or click Load synthetic fixture to inspect sample kind 35128, 15128, and 10002 records.

What works: Real SHA-256 canonical event ID verification over [0,pubkey,created_at,kind,tags,content], strict NIP-01 field validation, publisher & namespace version grouping, exact manifest stacking across publishers, NIP-65 relay role parsing, and explicit unknown classification when metadata is sparse.

Limitations: Structural and canonical ID verification only—signatureVerified is explicitly reported as false because BIP-340 secp256k1 verification is not bundled in this zero-dependency static app. Makes zero network calls and never downloads remote nsite files. Status is testing (browser-verified).

Where your data goes: Imported event sets stay in browser localStorage until you click Clear. Nothing is transmitted over a network.
