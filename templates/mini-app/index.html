Pocket Counter

Offline example · WIP template

What is this?

A tiny counting app demonstrating mini-app Help and skins.

Start: Use +1 and −1 to change the count; Reset returns it to zero.

Status: Development example, not a verified Android release.

Data: The count and skin stay in this browser's local storage when available. No network or device permission is required.
